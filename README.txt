MINDMATE AI - JAVASCRIPT PROJECT
================================

Project: AI-style mental wellness check-in prototype
Theme: SDG 3 - Good Health and Well-being

FILES
-----
index.html       Main webpage
css/style.css    Styling and responsive layout
js/app.js        Mood selection and demo chatbot logic

HOW TO RUN
----------
1. Extract the ZIP folder.
2. Open the MindMate_AI_JavaScript folder.
3. Double-click index.html to open it in a modern browser.
4. Select a mood and send messages to test the demo chatbot.

IMPORTANT
---------
This is a frontend demo. The chatbot uses predefined JavaScript rules;
it is not connected to a real AI model and does not diagnose or treat
mental health conditions. Do not enter private or sensitive information.
For a production deployment, add a secure backend, privacy controls,
professional review, and verified local support resources.
